# Trigger-delay background data

Generated by `../collect_trigger_delay_background.py` using the live AWG5208
and ATS937x configuration from `demo.ipynb`.

Run from the repository root with:

```powershell
C:\Users\cluster\anaconda3\envs\scqenv\python.exe -m testfolder.collect_trigger_delay_background
```

- Readout gain: 0 (background-only acquisition)
- Marker length: 40 ns
- External-trigger LSB masking: enabled
- DC-offset removal: disabled
- Trigger delays: 0, 100, 200, and 400 ns
- Integration window: 100 ns
- Averages per delay: 1000

`trigger_delay` moves the integration window within a record; every raw record
still begins at the received marker edge.

The `background_*` files use one independent acquisition per trigger delay and
therefore include run-to-run ADC offset drift. The `same_acquisition_*` files
apply all four windows to the same raw records and isolate the within-record
trigger-delay dependence.

The `waveform_*` files use gain 1 and the same 40 ns marker. They show the raw
50 MHz carrier, demodulated envelope, and integrated IQ amplitude for each
trigger-delay window without mixing those waveform values into the zero-gain
background controls. The IQ outputs include separate I/Q time traces and
per-shot I-Q constellation plots.
